One original one-line excuse an AI agent gives after failing a task: it asked a second model for a second opinion, and now both models are blaming it in a group chat it can't leave. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
